# NeoForge-Mods-Repo

Repositório de mods para Minecraft 1.21.1 com NeoForge + Kotlin.

## Mods

### [LittleUtils](./littleUtilsMod)
Mod de utilidades server-side:
- Durability Warning (action bar)
- Death Coords
- Fast Sleep
- `/craft` command
- AFK Detection

### [MinecraftWebBrowserExplorerMod](./MinecraftWebBrowserExplorerMod)
Mod que permite construir ecrãs multi-bloco com browser Chromium (MCEF).
*Em desenvolvimento/planeamento.*

---

**Requisitos:** JDK 21, NeoForge 21.1.172, Kotlin for Forge
