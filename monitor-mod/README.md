# Monitor Mod — NeoForge 1.21.1 + Kotlin

Mod que permite construir ecrãs multi-bloco no Minecraft que funcionam como browsers reais (Chromium).

## Funcionalidades Planeadas

- Bloco de monitor que se junta a adjacentes para formar um ecrã unificado
- Renderização com MCEF (Chromium Embedded Framework) para suportar YouTube, Spotify, etc.
- Input de rato e teclado no browser
- Suporte a Widevine para DRM (Netflix, Disney+)
- Tamanhos de 2×2 até 48×27 blocos (16:9)
